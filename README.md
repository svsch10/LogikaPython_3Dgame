## Реалізація механіки стрільби
### 1. Додавання пістолета
**1. Створення простої моделі пістолета**
+ Створити просту лоуполі-модель пістолета.
+ Дозволяється спрощений варіант без курка та дрібних деталей.
+ Модель створювати за допомогою **Extrude** (E), **Loop Cut**(Ctrl+R).
+ Додати матеріали (1–2 кольори достатньо).

**2. Підготовка файлу персонажа**
+ Перед початком роботи створити копію файлу персонажа `hero_anim_gun.blend`
+ Відкрити створену копію — далі всі зміни виконуються лише в ній.

**3. Зміна анімацій з урахуванням пістолета**
1. Підготовка пози рук
+ Відкрити проєкт персонажа.
+ Перейти у **Pose Mode**.
+ У **Action Editor** вибрати анімацію **idle**.
+ Перейти на перший ключовий кадр.
+ Розташувати руки персонажа в позицію для стрільби.
+ Перезаписати перший ключовий кадр: фокус у **viewport**; (*A — виділити все, I → Location / Rotation / Scal_e*).
2. Додавання пістолета до сцени
+ Додати модель пістолета через: **File** → **Append** → **Object**.
+ Розташувати пістолет у руках персонажа, вирівняти положення та поворот.
3. Додавання кістки для пістолета
+ Перейти в **Edit Mode** арматури.
+ Додати нову кістку для пістолета: розмістити її всередині моделі пістолета.
+ Зробити нову кістку дочірньою до головної: **Ctrl+P** → **Keep Offset**.
+ Перевірити в **Pose Mode**, що кістка рухається разом із персонажем.
+ Перезаписати перший ключовий кадр анімації **idle** вже з кісткою пістолета.
4. Прив’язка пістолета до кістки
+ Перейти у **Object Mode**.
+ Виділити спочатку пістолет, потім кістку пістолета.
+ Перейти у **Edit Mode** та переконатись, що виділена тільки кістка пістолета.
+ Повернутися в **Object Mode** та виконати **Ctrl+P** → **Bone**.
5. Оновлення всіх анімацій
+ Перейти у **Pose Mode**.
+ Для кожної анімації виконати такі кроки.
  + У **Action Editor** виділити перший ключовий кадр, де позиція рук і пістолета правильна.
  + У **viewport** виділити: кістки рук, кістку пістолета (щоб в **Action Editor** відображались тільки їхні ключові кадри).
  + Скопіювати ключові кадри (**Ctrl+C**)
  + Перейти на інші ключові кадри анімації.
  + Обов’язково виділити ключовий кадр (не просто пересунути повзунок).
  + Вставити кадри (**Ctrl+V**).

### 2.Додавання пострілу
1. Додавання **RayCast** для пострілу
+ Відкрити сцену головного персонажа та додати до нього **RayCast3D**, який буде використовуватись для визначення напрямку пострілу.
+ Розташувати **RayCast** у районі пістолета або дула та зорієнтувати його так, щоб він дивився вперед, у напрямку стрільби персонажа. 
2. Створення сцени кулі
+ Створити окрему сцену для кулі, використовуючи **RigidBody3D** як кореневий вузол. Додати до нього **CollisionShape3D** з простою формою, а також **MeshInstance3D** для візуального відображення.
+ Сцену кулі зберегти в окремий файл, щоб надалі можна було створювати її екземпляри під час стрільби.
3. Налаштування `action` для пострілу
+ Перейти у **Project Settings** і в розділі **Input Map** створити нову дію для пострілу, наприклад `shoot`. Призначити для цієї дії зручну клавішу або кнопку миші, яка буде використовуватись для стрільби в грі.
4. Реалізація пострілу
+ У скрипті головного персонажа реалізувати логіку створення пострілу. При спрацьовуванні `action shoot` необхідно створювати екземпляр сцени кулі, розміщувати його в позиції **RayCast**.
+ Після цього перевірити що кулі з’являються саме в потрібному місці та летять у правильному напрямку, і за потреби скоригувати позицію або розрахунок напряму.
5. Перевірка положення та напрямку кулі
+ Запустити сцену та переконайтись, що кулі створюються коректно, не з’являються всередині персонажа і рухаються вперед відповідно до напрямку пострілу.
+ Якщо напрямок або позиція неправильні, відрегулювати розташування **RayCast** або логіку задання трансформації кулі.
6. Скрипт руху кулі та зіткнення
+ Додати до сцени кулі скрипт, який відповідатиме за її рух, використовуючи імпульс **RigidBody3D**. У властивостях кулі увімкнути **Contact Monitor** і встановити `Max Contacts Reported = 1`. Через параметр **Gravity Scale** в інспекторі відрегулювати вплив гравітації, щоб куля не падала занадто швидко або взагалі летіла по прямій.
7. Час життя кулі та її видалення
+ Додати змінну часу життя кулі та зменшувати її з урахуванням `delta`. Коли час життя кулі закінчується, викликати `queue_free()`.
