## Реалізація виду від першої особи та третього виду зброї
**1. Підбирання предметів на рівні**

Реалізувати підбирання зброї. Після зіткнення зі зброєю вона повинна зникати зі сцени, а у персонажа має з’являтися можливість користуватись нею.

**2. Камери для різних режимів гри**

Додати дві камери: для виду від третьої особи та для виду від першої особи. Камеру від першої особи розташувати так, щоб вона була максимально близько до центру напрямку пострілу рушниці для того, щоб приціл на екрані збігався з променем **RayCast** під час стрільби.

**3. Автоматична зміна камери при перемиканні зброї**

Зробити так, щоб при перемиканні зброї змінювався і вид камери: з пістолетом залишається вид від третьої особи, а з рушницею та снайперською гвинтівкою вмикається вид від першої особи. Перевірити, що перемикання відбувається стабільно, а неактивна камера не впливає на зображення.

**4. Інтерфейс прицілу для рушниці**

Додати елементи інтерфейсу через **CanvasLayer** і розмістити приціл для рушниці у центрі екрана, використовуючи прив’язки (`anchors`), щоб він завжди залишався по центру при будь-якій роздільній здатності. Реалізувати логіку, щоб приціл для рушниці з’являвся лише тоді, коли активна рушниця і увімкнено вид від першої особи, а при переході на вид від третьої особи приціл зникав. Для перевірки точності увімкнути у налагодженні відображення колізій, щоб бачити, куди реально спрямований **RayCast**.

**5. Додавання третього виду зброї: снайперська гвинтівка**

Додати у гру третій вид зброї — снайперську гвинтівку, яка також може підбиратися на рівні та додаватися у список зброї персонажа. Створити для неї окремий **RayCas**t, який виходить прямо з центру камери від першої особи (та знаходиться в камері), і встановити довжину променя 50+ метрів, щоб забезпечити більшу дальність. Додати окремий приціл для снайперської гвинтівки та затемнення по краях екрана (картинка), а також змінити FOV камери на менше значення, щоб отримати ефект наближення.

**6. Постріл і баланс для різних видів зброї**

Налаштувати стрільбу так, щоб кожен вид зброї мав свої параметри, зокрема час перезарядки та кількість шкоди, і щоб логіка стрільби працювала тільки для активної зброї. Для рушниці та снайперської гвинтівки реалізувати постріл через **RayCast** із перевіркою попадання у ворога та викликом `damage`, а для пістолета залишити варіант із кулею, що створюється як інстанс.

**7. Обмеження вертикального руху камери для снайперки**

Зробити так, щоб вертикальний рух камери мишкою працював тільки під час використання снайперської гвинтівки, а кут підйому та опускання був обмежений через `clamp`, щоб камера не могла крутитися надто високо або надто низько. Перевірити, що для інших видів зброї ця логіка не вмикається.
