## 2. Створення об'єктів оточення. Сцени та екземпляри
### Створення лавочки

**1. Форма лавочки**
+ Додати примітив **Cube**.
+ Відмасштабувати його до розміру сидіння лавочки.
+ Перейти у **Edit Mode**.
+ Виконати **Loop Cut** та за допомогою **коліщатка миші** додати одразу кілька розрізів, щоб розбити форму на клітинки.

**2. Ніжки та деталі**
+ Виділити нижні грані сидіння.
+ Виконати **Extrude вниз** для створення ніжок.
+ За бажанням додати спинку або додаткові елементи.

**3. Матеріали**
+ Створити кілька матеріалів.
+ У **Edit Mode** виділити різні грані лавочки.
+ Призначити **різні матеріали різним граням** на власний смак.
+ Перевірити результат у **Material Preview**.

**4. Збереження**
+ Зберегти модель у форматі **`.blend`** з відповідною назвою файлу.
