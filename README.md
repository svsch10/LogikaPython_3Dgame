## Створення об'єктів оточення. Сцени та екземпляри
### Створення лавочки

**1. Форма лавочки**
+ Додати примітив **Cube**.
+ Відмасштабувати його до розміру сидіння лавочки.
+ Перейти у **Edit Mode**.
+ Виконати **Loop Cut** та за допомогою **коліщатка миші** додати одразу кілька розрізів, щоб розбити форму на клітинки.

**2. Ніжки та деталі**
+ Виділити нижні грані сидіння.
+ Виконати **Extrude вниз** для створення ніжок.
+ За бажанням додати спинку або додаткові елементи.

**3. Матеріали**
+ Створити кілька матеріалів.
+ У **Edit Mode** виділити різні грані лавочки.
+ Призначити **різні матеріали різним граням** на власний смак.
+ Перевірити результат у **Material Preview**.

**4. Збереження**
+ Зберегти модель у форматі **`.blend`** з відповідною назвою файлу.

### Створення 3D-будинку

**1. Базова форма**

+ Додати примітив **Cube**.
+ Відмасштабувати його до розміру будинку.
+ Перейти у **Edit Mode**.

**2. Дах**

+ Виділити верхні грані.
+ Створити дах за допомогою **Extrude** та переміщення вершин (двосхилий або плоский — на вибір).

**3. Двері та вікна**

+ Додати **Cube** для дверей і вікон та розташувати їх так, щоб вони перетинали стіни.
+ Виділити будинок і додати модифікатор **Boolean (Difference)**.
+ Вказати куби як об’єкти для вирізання та застосувати модифікатор.
+ Видалити допоміжні куби.
+ Створити рамки вікон (за допомогою **Loop Cut**, **Inset** та **Extrude)**

**4. Матеріали**

+ Створити матеріали для: даху, стін, дверей, рам, скла у вікнах, інших елементів на власний розсуд.
+ У **Edit Mode** виділити відповідні грані.
+ Призначити матеріали різним частинам будинку.
+ Перевірити вигляд у **Material Preview**.

**5. Експорт**

+ Зберегти модель у форматі **`.blend`**.
+ Експортувати модель у форматі **`.gltf`** для використання в Godot.

### Godot — сцена будинку

**1. Створення сцени будинку**
+ Створити нову сцену на основі **StaticBody3D**
+ Додати до нього модель будинку;
+ Додати **CollisionShape3D** для зіткнень.
+ Налаштувати **CollisionShape** під форму будинку.
+ Зберегти сцену як `house.tscn`.

**2. Додавання на рівень**
+ Відкрити головну сцену рівня.
+ Додати **екземпляри сцени будинку** (кілька будинків).
+ Розташувати їх на рівні.
+ Змінити **матеріал головної платформи** (земля / підлога).

**3. Додавання лавочок**
+ Створити сцену лавочки
+ Додайти екземпляри сцени лавочки на головну сцену
