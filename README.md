## Створення ворогів та налаштування їх поведінки
### 1. Blender — створення моделі ворога

**1. Основа**

+ Додати примітив **Cube**.
+ Додати модифікатор **Subdivision surface** із значенням **Levels Viewport = 3**, або 4 для більш високополігональної моделі.

**2. Форма тіла**

+ Перейти в режим редагування.
+ За допомогою **Loop Cut** створити форму тіла вашого персонажа

**3. Завершення створення тіла**

+ Додати очі, руки, ноги для персонажа, використовуючи модифікатори **Subdivision surface** та **Mirror,** інструменти  **Loop Cut**, **Inset** та **Extrude**
+ Застосувати модифікатори.

**4. Матеріали**

+ Створити матеріали для різних частин моделі на власний розсуд.

**5. Експорт**

+ Зберегти модель у форматі **`.blend`**.
+ Експортувати модель у форматі **`.gltf`** для використання в Godot.

### 2. Godot — патрулювання

**1. Підготовка сцени ворога**

+ Створити окрему сцену для ворога на основі вузла **CharacterBody3D** (наприклад **enemy.tscn**).
+ Додати потрібний колайдер та модель ворога в кореневий вузол.
+ Прикріпити до кореня скрипт для логіки патрулювання
+ Додати до скрипта змінні для збереження довжина маршруту, швидкості руху, швидкість розвороту.
+ Реалізувати рух уперед, зупинку на кінці маршруту, плавний розворот на 180°, а після розвороту — рух у зворотному напрямку

**2. Додавання ворогів на головну сцену**

+ Відкрити головну сцену рівня.
+ Додати **екземпляри ворога** на сцену та протестувати його роботу.
+ Додати ще одного ворога, повернути його під іншим кутом і встановити йому іншу довжину маршруту. Перевірити чи все працює правильно
