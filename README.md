## Анімація
### 1. Blender — створення скелетної анімації

**1. Підготовка до анімації**

+ Зробити копію файлу головного персонажа у форматі `.blend`.
+ Назвати файл, наприклад: `hero1_anim.blend`.
+ Переконатися, що **всі модифікатори застосовані** (`Apply`).
+ Особливу увагу звернути на модифікатор **Mirror** — він **обов’язково має бути застосований** перед створенням скелета.

**2. Створення скелета (Armature)**

+ Додати об’єкт `Armature`.
+ Увімкнути режим `In Front`, щоб кістки було добре видно всередині моделі.
+ Створити базовий набір кісток: корпус (spine), ноги, руки.
+ Структура має бути простою та зрозумілою, без надмірної деталізації.
+ Виділити модель персонажа, потім скелет.
+ Виконати `Parent → With Automatic Weights`.
+ Перевірити коректність деформації у `Pose Mode`.

**3. Створення анімацій**

+ За допомогою **Action Editor** створити дві анімації:
    -   `idle` — стан спокою,
    -   `jump` — стрибок.
+ У `Action Editor` **обов’язково увімкнути значок щита (Fake User)** для кожної анімації. Це запобігає випадковому видаленню анімацій під час збереження файлу.

**4. Завершення та збереження**

+ Зберегти файл **`.blend`** з анімацією.
+ Модель персонажа **перезаписати** (той самий **`.gltf`**), щоб у Godot автоматично підтягувалась оновлена версія з анімаціями.

### 2. Godot — перемикання анімацій

**1. Налаштування анімацій в `AnimationPlayer`**

+ для анімації **`idle`** увімкнути зациклення (`Loop`);
+ для анімації **`jump`** зациклення **вимкнене**.

**2. Логіка перемикання анімацій**

+ Логіка реалізується у скрипті персонажа.
+ Якщо персонаж **на землі** → відтворюється `idle`.
+ Якщо персонаж стрибає → відтворюється `jump`.
+ Використати перевірку `is_on_floor()` та перевіряти поточну анімацію, яка програється `AnimationPlayer.current_animation`
