## Фінальне оформлення проєкту
**1. Підготовка текстур і робота в Blender**  
У папці проєкту створити у **assets** нову папку **textures** і зберегти туди знайдені текстури штукатурки, черепиці, деревини тощо.  
Відкрити проєкт будинку та одразу створити його копію з новою назвою, наприклад **house_txt.blend**.  
Накласти текстуру штукатурки на основний каркас будинку, замінивши колір матеріалу на текстуру.  
Створити окремий матеріал для даху, застосувати його тільки до скатів і накласти текстуру черепиці.  
Додати текстуру для дверей, якщо потрібно. Спробувати також у воркспейсі **Image Paint** створити нове зображення і намалювати прості деталі прямо на моделі.  

**2. Використання текстур у Godot**  
Додати текстуру трави в Godot до платформи через **Albedo** → **Texture** → **Load**. Відрегулювати масштаб через **UV1**, щоб текстура виглядала природно і не була надто розтягнута.  

**3. Відображення життів у інтерфейсі**  
У **HUD** додати зображення сердечка через **ImageRect** і текстовий елемент **Label** для відображення кількості HP. Вивести значення HP у Label на початку гри у функції **`_ready`**, а також оновлювати його у функції **`damage`**, щоб значення змінювалось під час отримання шкоди.  

**4. Частинки при попаданні куль**  
Створити окрему сцену з частинками для ефекту іскор при попаданні куль. Налаштувати їх так, щоб вони розлітались у різні боки. Додати ці ефекти для пострілів з рушниці та снайперської гвинтівки, щоб при попаданні у поверхні або ворогів з’являлись іскри. За бажанням спробувати створити різні варіанти частинок для колізій з різними типами об’єктів.  

**5. Налаштування освітлення сцени**  
Додати **WorldEnvironment** і змінити його параметри, щоб сцена виглядала більш атмосферно. Підібрати налаштування яскравості, кольору та загального освітлення так, щоб рівень виглядав приємніше і об’ємніше.  

**6. Стартова сцена з меню**  
Створити окрему стартову сцену з кнопкою “Грати”, яка буде запускати основний рівень. Створити просту тему для інтерфейсу і змінити вигляд кнопки: підібравши за потреби колір, шрифт, заокруглення та виконати інші налаштування на ваш смак.  

**7. Сцени виграшу та програшу**  
Створити окремі сцени для виграшу та програшу. Перехід на сцена програшу повинен з’являтися, коли у головного персонажа закінчується HP, а сцена виграшу — коли виконана головна мета рівня, наприклад знищені всі вороги або пройдена вся територія. Додати на ці сцени простий текст із повідомленням про результат і кнопку для повернення в головне меню.
