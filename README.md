## Blender — створення 3D-персонажа

**1. Налаштування робочого середовища**  
* Запустити Blender (будь-яка версія від 2.8 і вище).  
* Переконатися, що відкрито стандартний Workspace Layout.

**2. Створення першої версії персонажа**  
* Додати примітив Sphere.  
* Створити зі сфери простого персонажа-смайла. Відмасштабувати модель до розміру приблизно 1 метр.  
* Додати очі з використанням примітивів.

**3. Матеріали**  
* Увімкнути **Material Preview** для роботи з матеріалами.  
* Створити матеріал для персонажа.  
* Змінити колір смайла.

**4. Збереження та експорт**  
* Створити папку проєкту гри.  
* Усередині проєкту створити структуру: **_assets/models_**  
* Зберегти файл персонажа у форматі **.blend** в папку **assets/models**.  
* Експортувати модель у форматі **.gltf** в папку **assets/models**.

## Godot — імпорт і рух персонажа

**1. Створення проєкту**  
+ Запустити Godot.  
+ Створити новий проєкт у папці проєкту гри.

**2. Створення платформи**  
+ Створити вузол StaticBody3D.
+ Додати до нього:  
  + **MeshInstance3D** для форми платформи;  
  + **CollisionShape3D** для зіткнень.  
+ Налаштувати розмір та позицію платформи.

**3. Створення головного персонажа**  
+ Створити вузол **CharacterBody3D**.  
+ Додати всередину модель персонажа.  
+ Повернути модель всередині **CharacterBody3D** на 180° у **Front View**.  
+ Перевірити, що персонаж рухається вперед правильно.

**4. Сцена та запуск**  
+ Додати світло.  
+ Додати камеру.  
+ Запустити сцену та перевірити, що вона коректно відображається.

**5. Керування персонажем**  
+ Додати скрипт керування до **CharacterBody3D**.  
+ Налаштувати рух персонажа.  
+ Налаштувати стрибок персонажа.  
+ Запустити гру та перевірити керування.

**6. Виправлення помилок**  
+ Якщо персонаж рухається не в той бік — змінити обертання моделі всередині **CharacterBody3D**.  
+ Перевірити коректність зіткнень персонажа з платформами.
